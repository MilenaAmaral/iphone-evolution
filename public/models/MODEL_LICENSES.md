## Blocked assets

No additional iPhone GLBs were added for the intermediate timeline entries. The only local generator for those entries, `scripts/generate-device-models.mjs`, explicitly produces abstract reference shapes and is not a faithful representation of any official iPhone design. It must not be presented as an official device model.

To complete the all-3D version, each missing model needs a source URL, an explicit license that permits redistribution in a public portfolio/GitHub repository, and an optimization record. Until that evidence exists, the current lightweight 2D fallback remains the honest representation.
